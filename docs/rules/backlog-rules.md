# Backlog rules

**What the backlog is.** The backlog is the one file holding every question kept for later: a question a docket left undecided and nothing needed, which would otherwise be dropped. It holds questions and nothing else.

**Who reads it.** The human, to pick a question up. /cycle-plan, to enter a question and to take one out. Nothing reads it to pick a question up on the human's behalf.

**Lifetime.** One file, `docs/backlog.md`, titled "# Backlog", created once by the human, never numbered, never deleted. With nothing to hold it reads "None."

**Entry.** One bullet per question. Its line opens with a label, B1 upward, one above the highest the file has ever held on any branch or in the history, never reused; then the question. Two sub-bullets, Reason and Owner, as the docket rules give them for an open question. No Needed by: a question reaches the backlog only when nothing needs its answer.

**Entering.** A question enters when a docket leaves it undecided, nothing needs its answer, and the human keeps it rather than drops it. The human may enter a question that never went through a docket.

**Leaving.** An entry leaves when its question is decided and a cycle file carries a task that delivers the decision, or when the human strikes it.

**Writing.** Write a question as the docket rules write an open question. Never say what happened, when, or which docket it came from. Name code by file and symbol, never by line number.
