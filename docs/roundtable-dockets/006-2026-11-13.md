## Lesser decisions

- LCD5. The component that dims the screen for a guest is named `GuestScrim`, and the context that opens it `GuestScrimContext` in `frontend/src/lib/viewer.ts`; no name in the code keeps "prompt" for either. `useWriteGuard` keeps its name.
  - Facts: PDR 058 shows no sentence with the press. The component renders `Scrim` alone (ADR 134). The component is `LogInPrompt` in the code. A list of choices dims the screen too.
  - Rejected: The name `LogInPrompt` kept, because the component shows no prompt. The name `GuestDimming`, because it hides that the component is `Scrim`. The name `DimmedScreen`, because a list of choices dims the screen too. The name `WriteRefusal`, because it says nothing of what is drawn.
  - Becomes true: The developer reads from the component's name whom it is for and what it renders, and finds no "prompt" among the code's names for the screen dimmed for a guest.
- LCD6. `Banner` and `ExampleBanner` take a ref, and `AppShell` holds the guest's banner's ref beside the one of "Log in".
  - Facts: `Scrim` leaves lit the elements its caller names (ADR 133), and the screen dimmed for a guest names the guest's banner and "Log in" (ADR 134). `Banner` takes no ref.
  - Rejected: None.
  - Becomes true: `AppShell` reaches the guest's banner as it reaches "Log in".
